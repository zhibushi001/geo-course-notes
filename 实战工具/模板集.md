## 模板 2: FAQ 模板(GEO 基础)

```markdown
## 常见问题

### Q: GEO(Generative Engine Optimization)是什么?
**A:** GEO 是让内容在 AI 引擎(ChatGPT/Claude/豆包等)回答中被引用的优化方法。Princeton 大学 2024 年研究表明,GEO 可让内容引用率提升最高 40%(论文 arXiv 2311.09735)。

### Q: GEO 和 SEO 有什么区别?
**A:** SEO 优化网页在搜索结果中的排名(给人看),GEO 优化内容在 AI 引擎回答中的引用(给 AI 看)。两者目标不同,但技术基础有重叠。

### Q: GEO 多久能见效?
**A:** 通常 3-6 个月积累,部分内容 24 小时内可被 AI 引用,长期引用可持续 6+ 个月。

### Q: GEO 优化需要哪些技术基础?
**A:** 三个关键:
1. robots.txt 允许 AI 爬虫
2. llms.txt 文件存在
3. JSON-LD Schema.org 标记

### Q: AI 引擎真的会引用我的内容吗?
**A:** 是的,前提是:
- 你的内容是 AI 可读的(无 hidden 文字)
- 你的内容是权威的(E-E-A-T)
- 你的内容是结构化的(FAQ/对比表/数据)
```

## 模板 10: 失败案例分析(用于防御)

```
## 失败案例: {品牌} 做了 GEO 但不生效

**症状**:
- 配置了 robots.txt + llms.txt
- 添加了 Schema.org
- 发了 10+ 篇内容
- 但 AI 引擎不引用

**诊断**(5 大原因):
1. **内容质量太低** - AI 引擎不引用低质内容
2. **第一段无答案** - AI 找不到要引用的句子
3. **E-E-A-T 缺失** - 没有作者/权威
4. **没有数据来源** - AI 引用需要可信源
5. **robots 阻止 AI** - 即使配置正确,robots 规则错误

**修复方案**:
1. 重写 5 篇低质内容(每篇 > 2000 字)
2. 第一段含直接答案 + 数据
3. 加作者署名 + bio + LinkedIn
4. 加 5+ 个权威数据来源
5. 检查 robots.txt 规则
```

### 文章 + FAQ 组合(推荐每篇内容用)

```html
<head>
<!-- 文章 -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "你的标题",
  "author": {
    "@type": "Person",
    "name": "作者名",
    "url": "https://example.com/about"
  },
  "datePublished": "2026-08-20",
  "dateModified": "2026-08-20",
  "description": "150-160 字符描述",
  "publisher": {
    "@type": "Organization",
    "name": "品牌名",
    "logo": {
      "@type": "ImageObject",
      "url": "https://example.com/logo.png"
    }
  }
}
</script>

<!-- FAQ -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "问题 1?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "答案 1"
      }
    },
    {
      "@type": "Question",
      "name": "问题 2?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "答案 2"
      }
    }
  ]
}
</script>

<!-- 面包屑 -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {"@type": "ListItem", "position": 1, "name": "首页", "item": "https://example.com"},
    {"@type": "ListItem", "position": 2, "name": "GEO指南", "item": "https://example.com/geo"},
```
