## 案例 1: 网站有 robots.txt 但 AI 不抓

**症状**:
- 百度 / Google 收录正常
- AI 引擎完全没引用
- 检查 robots.txt 发现没配置 AI 爬虫

**根因**:
```txt
# 错误 - 只配置了 Googlebot
User-agent: *
Disallow: /

User-agent: Googlebot
Allow: /
```

只配置 Googlebot,其他 AI 爬虫**默认被 User-agent: * 阻止**。

**修复**:
```txt
# 正确
User-agent: *
Disallow: /wp-admin/
Disallow: /private/

User-agent: Googlebot
Allow: /

User-agent: GPTBot
Allow: /

User-agent: ClaudeBot
Allow: /

# 其他 AI 爬虫...
```

**耗时**:5 分钟
**教训**:**默认行为是禁止**,必须显式允许

## 案例 2: llms.txt 存在但 AI 不读取

**症状**:
- 域名/llms.txt 返回 200
- AI 引擎仍然引用旧内容
- 流量没增加

**根因**:
```
1. llms.txt 内容太简略(< 100 字)
2. AI 引擎优先级低于 HTML
3. 文件路径不对
```

**修复**:
```
1. 写 1000+ 字符的完整 llms.txt
2. 包括:
   - 产品/服务列表(每个带链接 + 描述)
   - 数据点(数字 + 来源)
   - 关于(团队/历史)
3. 在 robots.txt 加:
   Sitemap: https://example.com/llms.txt
4. 在 HTML <head> 加:
   <link rel="alternate" type="text/plain" href="/llms.txt" title="LLM-friendly content">
```

**耗时**:2-4 小时
**教训**:**llms.txt 不是装上就有用**,要内容丰富

## 案例 3: Schema.org 标记但搜索结果不显示富文本

**症状**:
- Schema.org 验证通过
- 搜索结果还是普通标题/描述
- 不显示星级、价格、FAQ

**根因**:
```
1. Schema 类型不匹配页面
2. 数据不完整(必需字段缺失)
3. Google Search Console 未验证
```

**修复**:
```
1. 确认页面有"显示价值"
   - 文章 → Article + Author + date
   - 产品 → Product + price + availability
   - FAQ → FAQPage + 所有 Q&A
2. 用 Google Rich Results Test 验证
3. Search Console → 增强功能 → 检查
4. 等待 2-4 周 Google 重新抓取
```

**耗时**:2-4 周(等 Google 重新处理)
**教训**:**Schema 不是即时的**,要 Google 处理

## 案例 4: AI 引用但不带来流量

**症状**:
- 15 提示词测试 60% 引用率
- 实际网站流量没增加
- 转化率不升反降

**根因**:
```
1. AI 引用但不点链接(0% 点击)
2. AI 引用"竞品"而不是你
3. AI 引用"老内容"导致用户预期不符
```

**诊断**:
```bash
# 看具体引用了什么
去 ChatGPT 问:"X 工具哪家好"
记录它引用的具体页面
看是你的哪篇 + 是不是第一段
```

**修复**:
```
1. 第一段含 CTA(让用户点击)
2. 加"了解更多"链接
3. 内容要"匹配 AI 引用的语境"
4. 在文中明确"我们提供 X 服务"
```

**耗时**:2-4 周
**教训**:**AI 引用 ≠ 用户点击**,需要优化点击

## 案例 5: 内容质量高但百度不收录

**症状**:
- 原创内容,数据来源齐全
- 提交百度资源平台
- 1 个月后还没收录

**根因**:
```
1. 网站新站(权重低)
2. robots.txt 错误
3. 服务器慢(超过 5 秒)
4. 内容太短(< 500 字)
5. 重复内容(被识别)
6. 内部链接少
7. 没有外链
```

**修复**:
```
1. 检查 robots.txt 和 sitemap
2. 提升服务器速度(< 3 秒)
3. 加内链结构
4. 在知乎/百家号发外链
5. 多提交几次
6. 等待 2-3 个月(新站正常)
```

**耗时**:1-3 个月
**教训**:**新站需要时间建立信任**

## 案例 6: GEO 做完后突然掉量

**症状**:
- 引用率 50%+
- 突然某周掉到 20%
- 没有任何修改

**根因**:
```
1. AI 平台政策变化(2024-2026 频繁)
2. 竞品发了新权威内容
3. 自己的内容被修改(被黑?)
4. llms.txt 失效
5. Schema 失效
```

**紧急诊断**:
```bash
# 1. 检查基础设施
python 实战工具/check_ai_crawlers.py 你的网站
python 实战工具/geo_audit.py 你的网站
curl 你的网站/llms.txt

# 2. 检查最近修改
git log --since="1 month ago"  # 看你改了什么

# 3. 检查流量来源
百度统计/Google SC 看哪个页面掉
```

**修复**:
```
1. 立即发 3-5 篇新内容(高频)
2. 检查被黑(改密码 + 查日志)
3. 提交百度 + 主动推送
4. 跨平台分发(知乎/百家号)
```

**耗时**:1-2 周恢复
**教训**:**GEO 是动态战场**,需要持续监测

## 案例 7: Schema.org 错误导致惩罚

**症状**:
- 添加了 Product schema
- 但产品已下架(状态=Discontinued)
- Google 警告"标记不符"

**根因**:
```
Schema 标记与实际页面内容不符
- 价格是 99,但 Schema 写 199
- 库存是 OutOfStock,Schema 写 InStock
- 评分 4.5,Schema 写 5.0
```

**修复**:
```
1. Schema 必须反映真实数据
2. 用 Google Rich Results Test 验证
3. 定期更新 schema(价格/库存)
4. 错误信息提交到 Search Console
```

**耗时**:1-2 周
**教训**:**Schema 准确性 = 信任 = AI 引用**

## 案例 8: 同一内容被 AI 引擎识别为"重复内容"

**症状**:
- 同一内容发到主站、知乎、百家号
- AI 引擎只引用最早出现的版本
- 其他平台版本被忽略

**根因**:
```
1. 平台之间 canonical 设置错误
2. 内容一字不差
3. 没有唯一标识
```

**修复**:
```
1. 主站加 canonical:
   <link rel="canonical" href="https://example.com/article">
2. 其他平台加原文链接
3. 主站内容稍微"长"5-10%
4. 用 datePublished 区分
5. 加 Schema Article 标记主站
```

**耗时**:1-2 周
**教训**:**多平台要分主次**,主站为王

## 案例 9: AI 训练数据污染被反噬

**症状**:
- 竞品在维基百科编辑了负面内容
- AI 引擎引用了"事实"
- 你的品牌被错误描述

**根因**:
```
1. 维基百科编辑战
2. 假新闻被抓取
3. 训练数据被污染
4. 反复输出错误信息
```

**修复**:
```
1. 立即编辑维基百科(需要可靠来源)
2. 发布反驳文章(带数据)
3. 提交给 AI 平台反馈
4. 长期建设正面内容
5. 监控 AI 引用是否准确
```

**耗时**:1-6 个月
**教训**:**AI 训练数据污染 = 长期作战**

## 案例 10: 内容农场模式被识别

**症状**:
- 每天发 10+ 篇
- 百度 AI 引用率不升反降
- 内容质量分低

**根因**:
```
1. AI 引擎检测"内容农场模式"
2. 高频发布触发阈值
3. 内容模板化
4. 没有真实编辑投入
```

**修复**:
```
1. 降低发布频率(每天 1-2 篇)
2. 每篇 2000+ 字
3. 加 E-E-A-T 信号
4. 加原创数据
5. 用人工编辑(不是纯 AI 生成)
```

**耗时**:1-3 个月恢复
**教训**:**质量 > 数量**

## 案例 11: 网站被负面 SEO 攻击

**症状**:
- 百度收录突然下降
- 反向链接暴增(几千条 spam)
- 关键词排名暴跌

**根因**:
```
1. 竞品发垃圾反向链接
2. 镜像你的内容到 spam 站
3. 黑链/暗链
```

**紧急修复**:
```
1. 百度站长平台 → 拒绝外链
2. 提交 spam 链接到百度
3. 加 Disavow 文件
4. 举报镜像
5. 加强 robots.txt
```

**修复时长**:2-4 周
**教训**:**负面 SEO 真实存在**,需要监控

## 案例 12: AI 内容检测误判

**症状**:
- 内容是人工写的
- AI 内容检测器说"100% AI 生成"
- AI 引擎因此不引用

**根因**:
```
1. AI 检测器不准确
2. 内容有 AI 辅助痕迹
3. 文风太"完美"(不像人写)
```

**修复**:
```
1. 加个性化内容(第一手经验)
2. 加 emoji/口语化表达
3. 加独特观点
4. 不要追求"AI 友好",要追求"人类友好"
5. 注明作者(真人 bio)
```

**耗时**:重写
**教训**:**AI 检测器 ≠ 真实 AI 引擎判断**

## 案例 13: 关键词竞争激烈

**症状**:
- 内容优化得很好
- 但关键词在百度前 3 都被大站占
- 永远做不到首页

**根因**:
```
1. 关键词难度太高
2. 没有足够权威性
3. 大站垄断(知乎/百度系/门户网站)
```

**修复**:
```
1. 找长尾关键词(更具体)
2. 做差异化角度
3. 在子领域深耕
4. 建立独特数据源
5. 长期持续优化
```

**耗时**:6-12 个月
**教训**:**关键词选择 > 内容质量**(重要)

## 案例 14: 移动端不友好

**症状**:
- 桌面端 GEO 评分 80
- 移动端 GEO 评分 30
- AI 引擎偏向移动端友好网站

**根因**:
```
1. 移动端布局错乱
2. 移动端加载慢
3. 移动端没有 Schema
4. 移动端禁用 JavaScript
```

**修复**:
```
1. 响应式设计
2. 移动端 < 2.5 秒加载
3. 移动端同样的 Schema
4. 测试 Google Mobile-Friendly Test
5. 用移动设备实际访问
```

**耗时**:1-2 周
**教训**:**移动端 = 主战场**(80% 流量)

## 🛡️ 防御原则

### 每月例行检查

```bash
# 1. AI 爬虫可见
python 实战工具/check_ai_crawlers.py 你的网站

# 2. GEO 准备度
python 实战工具/geo_audit.py 你的网站
```
