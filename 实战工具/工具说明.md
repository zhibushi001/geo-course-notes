# SEO+GEO 实战工具集 v1.0

5 个**即用型 Python 脚本**——每个都是**独立可运行**的。

## 工具清单

| # | 脚本 | 用途 | 难度 |
|---|---|---|---|
| 1 | `geo_audit.py` | GEO 准备度审计 | ⭐ |
| 2 | `llms_txt_generator.py` | llms.txt 自动生成 | ⭐ |
| 3 | `schema_generator.py` | Schema.org JSON-LD 生成 | ⭐ |
| 4 | `prompt_15.py` | 15 个 GEO 提示词测试 | ⭐ |
| 5 | `check_ai_crawlers.py` | robots.txt AI 爬虫检查 | ⭐ |

## 使用前准备

```bash
pip install requests beautifulsoup4
```

## 工具 1: GEO 准备度审计 (geo_audit.py)

### 功能
- 检查 robots.txt(允许 AI 爬虫)
- 检查 llms.txt 存在
- 检查 sitemap.xml
- 检查关键页面 SEO 基础
- 输出 0-100 分

### 使用
```bash
python geo_audit.py https://example.com
```

### 输出示例
```
============================================
  GEO 准备度审计
  目标: https://example.com
============================================

✓ robots.txt     - 9/12 个 AI 爬虫被允许 (75%)
✓ llms.txt       - 不存在 (-10)
✓ sitemap.xml    - 存在 (15 个 URL)
✗ Schema         - 未检测到
✓ 标题            - 32 字符
✓ 描述            - 142 字符
✓ H1            - 1 个

============================================
  评分: 62/100 (B-)
  建议: 添加 llms.txt + Schema.org 标记
============================================
```

## 工具 2: llms.txt 自动生成 (llms_txt_generator.py)

### 功能
- 自动爬取网站
- 提取主要页面
- 生成标准 llms.txt
- 支持自定义配置

### 使用
```bash
python llms_txt_generator.py https://example.com -o llms.txt
```

---

## 工具 3: Schema.org 生成器 (schema_generator.py)

### 功能
- 生成 6 种常见 Schema
- 输出 JSON-LD
- 复制即用

### 使用
```bash
# 交互式
python schema_generator.py
# 命令行
python schema_generator.py --type faq --output faq.json
```

### 支持类型
- FAQ (FAQPage)
- 文章 (Article)
- 产品 (Product)
- 组织 (Organization)
- 面包屑 (BreadcrumbList)
- HowTo

## 工具 4: 15 个 GEO 提示词 (prompt_15.py)

### 功能
- 15 个 GEO 测试提示词(7-5-3 黄金分布)
- 自动在 6 大 AI 平台查询
- 记录是否提到你的品牌

### 使用
```bash
# 测试你的品牌在 AI 中的引用
python prompt_15.py "我的品牌"

# 自定义提示词
python prompt_15.py --custom "我的 GEO 工具"
```

## 工具 5: AI 爬虫检查 (check_ai_crawlers.py)

### 功能
- 检查 robots.txt 是否允许 12+ AI 爬虫
- 输出白名单/黑名单
- 自动生成补丁

### 使用
```bash
python check_ai_crawlers.py https://example.com
```

### 输出示例
```
============================================
  AI 爬虫检查: https://example.com
============================================

✓ 允许: GPTBot (OpenAI 训练)
✓ 允许: ChatGPT-User (OpenAI 用户)
✗ 阻止: ClaudeBot (Anthropic 训练)
✗ 阻止: Claude-Web (Anthropic 用户)
✗ 阻止: PerplexityBot
✗ 阻止: Bytespider (豆包)
✗ 阻止: Google-Extended (Gemini 训练)
...

============================================
  评分: 2/12 (17%)
  ⚠️ 大部分 AI 爬虫被阻止!
  建议: 添加 User-agent 规则
============================================
```

## 工作流

```
Step 1: 审计
   python geo_audit.py https://example.com
   ↓
   得到评分 + 改进建议
   
Step 2: 生成 llms.txt
   python llms_txt_generator.py https://example.com
   ↓
   上传到 https://example.com/llms.txt
   
Step 3: 生成 Schema
   python schema_generator.py --type faq
   ↓
   嵌入到网页 <head>
   
Step 4: 配置 robots.txt
   python check_ai_crawlers.py https://example.com
   ↓
   按建议添加规则
   
Step 5: 测试 AI 引用
   python prompt_15.py "我的品牌"
   ↓
   记录 6 大平台结果
```
