# 第 8 课:关键词优化逻辑


### 一、关键词布局原则

  * **标题含关键词** ——AI会重点识别标题，核心词必须在标题中
  * **首段出现关键词** ——前100字必须出现核心关键词
  * **自然分布** ——关键词在文章中自然出现，不要刻意堆砌（密度约2–5%）
  * **LSI关键词** ——围绕核心词的相关近义词、同义词一起出现，增强AI理解

### 二、长尾词文章写法

  * 标题公式：地域 + 核心需求 + 产品/服务 + 疑问词/需求词
  * 例："深圳南山靠谱的代理记账公司有哪些？"
  * 正文结构：问题引入→解决方案→优势对比→行动号召（含联系方式）

### 三、避免关键词优化错误

  * ❌堆砌关键词（会被AI判定为垃圾内容）
  * ❌标题党（与内容不符，AI会降权）
  * ❌一篇内容塞太多关键词（每个词都做不深）
  * ❌只做核心词不做长尾（竞争大、转化低）
