## 工具 1: 百度搜索资源平台(必须)

**作用**:百度官方 SEO 数据 + 提交入口

### 注册

```
1. 访问 https://ziyuan.baidu.com/
2. 登录百度账号
3. 点击"添加站点"
4. 填入网站 URL
5. 选站点类型:
   - 主体(推荐)
   - 子目录
6. 完成验证(3 种方式):
   - 文件验证(推荐,最简单)
   - HTML 标签
   - DNS 解析
```

### 文件验证步骤

```
1. 下载验证文件 baidu_verify_xxxxx.html
2. 上传到网站根目录
   example.com/baidu_verify_xxxxx.html
3. 点击"完成验证"
4. 等待 1-24 小时审核
```

### 提交 sitemap

```
1. 进入站点管理 → sitemap
2. 填入 sitemap URL
   example.com/sitemap.xml
3. 提交后等待 1-7 天抓取
4. 查看"已抓取"数量
```

### 主动推送(必须做!)

```
1. 进入"链接提交"
2. 选"主动推送"(实时)
3. 每天推 10-20 条新 URL
4. 用 API 推送更高效:
   curl -H 'User-Agent: curl/7.0' \
     "https://data.zz.baidu.com/urls?site=example.com&token=YOUR_TOKEN" \
     -d "http://example.com/page1"
```

### 看数据

```
1. 索引量:被百度收录的页面数
2. 抓取频次:百度每天来抓几次
3. 关键词:你的网站在百度搜什么词有排名
4. 点击展现:你的网站在搜索结果出现的次数
5. 死链:百度发现你的死链
```

## 工具 2: 百度统计(可选,推荐)

**作用**:看流量来源 + 用户行为

### 注册

```
1. 访问 https://tongji.baidu.com/
2. 登录百度账号
3. 添加站点
4. 获取统计代码
```

### 安装代码

```html
<!-- 在 </head> 之前 -->
<script>
var _hmt = _hmt || [];
(function() {
  var hm = document.createElement("script");
  hm.src = "https://hm.baidu.com/hm.js?YOUR_ID";
  var s = document.getElementsByTagName("script")[0];
  s.parentNode.insertBefore(hm, s);
})();
</script>
```

### GEO 关键数据

```
1. 流量来源分析
   - 搜索引擎(百度/Google)
   - 外链(知乎/小红书)
   - 直接访问

2. 关键词分析
   - 用户搜什么词到你的站
   - 哪些关键词带来最多流量

3. 用户行为
   - 停留时间(影响 GEO)
   - 跳出率(影响 GEO)
   - 页面浏览路径
```

### GEO 关键指标

| 指标 | GEO 影响 |
|---|---|
| 停留时间 > 2 分钟 | ✅ AI 引擎认为"内容好" |
| 跳出率 < 40% | ✅ 内容相关 |
| 页面深度 > 3 页 | ✅ 用户深入 |
| 来源多样化 | ✅ 品牌权威 |

## 工具 3: Google Search Console(免费,推荐)

**作用**:Google 搜索数据(国际 SEO/GEO)

### 注册

```
1. 访问 https://search.google.com/search-console/
2. 登录 Google 账号
3. 添加资源类型:
   - 网址前缀(推荐) - 包含 http/https/www
   - 域名(需要 DNS 验证)
4. 验证:
   - HTML 文件
   - HTML 标签
   - Google Analytics
   - DNS TXT
```

### 提交 sitemap

```
1. 左侧菜单 → Sitemaps
2. 添加 sitemap URL
3. example.com/sitemap.xml
4. 等待 1-3 天抓取
```

### GEO 关键数据

```
1. 覆盖范围 → 索引状态
2. 增强功能 → 核心 Web 指标
3. 链接 → 外部/内部链接
4. 页面 → 哪些页面被收录
5. 体验 → Core Web Vitals
```

## 工具 5: Screaming Frog SEO Spider(本地工具)

**作用**:抓取你的网站,审计技术问题

### 安装

```
1. 访问 https://www.screamingfrog.co.uk/seo-spider/
2. 下载免费版(可爬 500 URL)
3. 安装到电脑
```

### 使用

```
1. 输入 URL
2. 爬取
3. 看 "Response Codes"
   - 200 正常
   - 301/302 重定向
   - 404 死链
   - 5xx 服务器错误
4. 看 "Page Titles"
   - 缺失标题
   - 标题过长
5. 看 "Meta Description"
   - 缺失
   - 重复
6. 看 "H1"
   - 缺失
   - 多个
7. 看 "Structured Data"
   - 检测到的 Schema
   - 错误
```

### GEO 关键

```
- 检测 AI 爬虫是否被 robots 阻止
- 检测哪些页面有/无 Schema
- 检测页面加载速度
- 检测内链结构
```

## 工具 6: Ahrefs / SEMrush(付费,可选)

**作用**:全功能 SEO 工具

### Ahrefs

```
1. 访问 https://ahrefs.com/
2. 注册 + 付费(~$99/月起)
3. Site Explorer
   - 输入域名
   - 看反向链接
   - 看关键词排名
4. Content Gap
   - 找竞品覆盖但你没覆盖的关键词
5. Keywords Explorer
   - 找 GEO 关键词
```

### GEO 用法

```
1. Content Gap 分析
   - 找竞品文章覆盖的关键词
   - 你没覆盖的 → 写新内容
2. 关键词意图分析
   - 哪些关键词 AI 引擎最常引用
3. 反向链接监控
   - 监控负向 SEO
```
