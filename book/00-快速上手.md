## 0.1 GEO 是什么?30 秒版

> **GEO(Generative Engine Optimization)** = 让内容在 **AI 引擎**(ChatGPT/Claude/豆包等)回答中被引用的优化方法。

**一句话类比**:
- **SEO** = 让百度把你的网站列在搜索结果(给人看)
- **GEO** = 让 ChatGPT 在回答时提到你的品牌(给 AI 看)

**实际数据**:
- Princeton 2024 年研究:**GEO 可让内容引用率提升最高 40%**
- C-SEO Bench 2025 年研究:**大多数内容改写方法无效或负效果**(SEO 基础更重要)
- 豆包月活 **3.6 亿**(2025)— AI 已经是新流量入口

## 0.4 第一步行动

如果评估结果让你想做下去,**今天就做这 3 件事**:

### 1. 创建 llms.txt(10 分钟)

```bash
python llms_txt_generator.py https://你的网站 -o llms.txt
# 上传到 https://你的网站/llms.txt
```

### 2. 配置 robots.txt(5 分钟)

把你网站的 robots.txt 改为:
```txt
User-agent: GPTBot
Allow: /

User-agent: ClaudeBot
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: Bytespider
Allow: /

User-agent: Google-Extended
Allow: /

User-agent: *
Disallow: /admin/
Disallow: /private/
```

### 3. 测试 AI 引用(15 分钟)

```bash
python prompt_15.py "你的品牌" -o test.md
# 然后去 6 大 AI 平台问
```

**3 件事 30 分钟。1 小时内看到效果!**
