## 🔍 Step 1: 基础设施检查(20 分钟)

### 1.1 robots.txt 配置

**检查方法**:
```bash
# 你的 robots.txt
curl https://example.com/robots.txt
```

**问题 1.1**: 没有任何 AI 爬虫配置

```txt
# 错误:只配置了 Googlebot
User-agent: Googlebot
Allow: /

# 正确:配置主要 AI 爬虫
User-agent: GPTBot
Allow: /

User-agent: ClaudeBot
Allow: /
User-agent: PerplexityBot
Allow: /

User-agent: Bytespider
Allow: /

User-agent: Google-Extended
Allow: /
```

**问题 1.2**: 错误地阻止了 AI 爬虫

```txt
# 错误(无意中阻止):
User-agent: *
Disallow: /

# 错误(只想到 SEO,没想到 GEO):
User-agent: GPTBot
Disallow: /
```

**问题 1.3**: 没有 Sitemap 声明

```txt
# 错误:robots.txt 没有 Sitemap
# 正确:加在文件最后
Sitemap: https://example.com/sitemap.xml
```

**自动化检查**:
```bash
python 实战工具/check_ai_crawlers.py https://example.com
```

**预期结果**:至少 6 个 AI 爬虫被允许(GPTBot/ClaudeBot/PerplexityBot/Bytespider/Google-Extended 等)

**检查方法**:

curl https://example.com/llms.txt

- [文章B](https://example.com/b): 描述

### 1.3 Schema.org 标记

**检查方法**:
- Google: https://search.google.com/test/rich-results
- Schema.org Validator: https://validator.schema.org/

**问题 1.7**: 没有 Schema

**问题 1.8**: Schema 错误

```json
// 错误(语法错):
{
  "@context": "https://schema.org",
  "@type": "Article"
  "headline": "标题"  // 缺少逗号
}

// 正确:
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "标题"
}
```

**问题 1.9**: Schema 在错误位置

```html
<!-- 错误:在 body 里 -->
<body>
<script type="application/ld+json">...</script>
</body>

<!-- 正确:在 head 里 -->
<head>
<script type="application/ld+json">...</script>
</head>
```

**自动化生成**:
```bash
python 实战工具/schema_generator.py
```

## 🔍 Step 2: 内容质量检查(30 分钟)

### 2.1 标题(Title)

**检查清单**:
- [ ] 长度 50-60 字符
- [ ] 含主关键词
- [ ] 含价值主张
- [ ] **不夸张**("震惊!99%...")

**问题 2.1**: 标题没有关键词
```html
<title>关于我们</title>  <!-- 错 -->
<title>GEO 完整指南 2026 - 30 天学会 - 品牌名</title>  <!-- 对 -->
```

**问题 2.2**: 标题过长(> 60 字符)
搜索引擎会截断

**问题 2.3**: 多页同标题
```html
<!-- 错:所有页面都用 "首页" -->
<title>首页 - 品牌名</title>
<title>首页 - 品牌名</title>

<!-- 对:每页唯一 -->
<title>GEO 完整指南 - 品牌名</title>
<title>AI 优化工具 - 品牌名</title>
```

---

### 2.2 第一段(关键!)

**问题 2.4**: 第一段没有直接答案

```html
<!-- 错(铺垫太多): -->
<p>在当今数字化时代,营销人员面临诸多挑战...</p>

<!-- 对(开门见山): -->
<p><strong>GEO 是让内容在 AI 引擎回答中被引用的优化方法</strong>。
Princeton 大学 2024 年研究表明,GEO 可让内容引用率提升最高 40%。
2026 年,豆包月活 3.6 亿,GEO 已成为企业标配。</p>
```

**问题 2.5**: 第一段超过 200 字
太长的第一段 AI 抓不到重点

**问题 2.6**: 没有数据来源
AI 引擎不引用"无源"内容

---

### 2.3 内容深度

**问题 2.7**: 内容太短(< 1000 字)
```python
# 检查方法
# 选中文字 → 看字数
# < 1000 字 = 几乎不被 AI 引用
```

**问题 2.8**: 没有 H2 章节
所有内容在一个段落里

**问题 2.9**: 没有 FAQ 块
AI 引擎特别喜欢 FAQ(数据 +156% 引用)

**问题 2.10**: 没有数据/来源
- ❌ "GEO 很重要"(无源)
- ✅ "GEO 可提升 40% 引用率(Princeton 2024)"

---

### 2.4 作者信息(E-E-A-T)

**问题 2.11**: 没有作者署名

```html
<!-- 错 -->
<article>
  <h1>GEO 指南</h1>
  <p>...</p>
</article>

<!-- 对 -->
<article>
  <h1>GEO 指南</h1>
  <p>作者:张三,资深 GEO 专家</p>
  <p>2026-08-20 更新</p>
  <p>...</p>
</article>
```

**问题 2.12**: 作者无 bio/链接
- AI 看不出作者权威性
- 解决:加作者 bio 页 + LinkedIn 链接

---

### 3.2 引用率 0-30%:严重问题

**可能原因**:
1. ❌ AI 爬虫根本访问不到
2. ❌ 内容质量太差
3. ❌ 第一段没答案
4. ❌ 没有 E-E-A-T
5. ❌ 没有数据来源

**诊断步骤**:
```bash
# 1. 检查 robots
python 实战工具/check_ai_crawlers.py https://example.com

# 2. GEO 准备度审计
python 实战工具/geo_audit.py https://example.com

# 3. 查 sitemap
curl https://example.com/sitemap.xml

# 4. 检查 llms.txt
curl https://example.com/llms.txt
```

---

### 3.3 引用率 30-60%:优化空间

**可能原因**:
- 内容有但不够权威
- FAQ 块不够
- 对比表少
- 缺少最新数据

**优化清单**:
- [ ] 加 5+ 个 FAQ 块
- [ ] 加 3+ 个对比表
- [ ] 加 2+ 个原创数据/研究
- [ ] 加作者 bio + LinkedIn
- [ ] 重写低质内容

---

### 3.4 引用率 60%+:保持

**做的事**:
- [ ] 每月监测(避免掉下去)
- [ ] 持续更新内容
- [ ] 跟踪竞品变化

## 🔍 Step 4: 时机和长期因素(等待)

### 4.1 时间不够

**问题 4.1**: 做了 1 个月,还没见效

**预期时间表**:
- 第 1 个月:基础设施搭建,AI 开始发现
- 第 2-3 个月:部分内容被引用
- 第 3-6 个月:稳定引用
- 第 6-12 个月:成熟

**不要灰心!**GEO 是长期游戏

---

### 4.2 关键词竞争激烈

**问题 4.2**: 我的内容不出现,因为竞品太权威

**解决**:
- [ ] 找长尾关键词(更具体)
- [ ] 做差异化角度
- [ ] 在子领域深耕
- [ ] 建立独特数据
