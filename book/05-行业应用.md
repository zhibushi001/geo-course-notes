## 5.2 B2B SaaS 行业(类似知不识)

### 行业特点

- 客户决策周期长(3-12 月)
- 内容影响决策权重高
- 关键词竞争激烈
- 主要靠**百度 + 知乎 + 公众号**获客

### GEO 优化重点

**1. 知乎深度内容**(权重高)

```
策略:
- 每周 1 篇深度回答(> 1500 字)
- 题目用"如何选择/对比/评估"型
- 加数据来源
- 末尾引导下载白皮书
```

**2. 百度生态**

```
- 百家号:每天 1 篇(> 800 字)
- 百度百科:申请公司词条(需新闻源)
- 百度知道:回答行业问题(不刷)
- 百度文库:上传白皮书
```

**3. 公众号**

```
- 深度长文(> 3000 字)
- SEO 友好标题
- 加 GEO 友好的 FAQ 块
```

### 关键 Schema

```json
{
  "@context": "https://schema.org",
  "@type": "SoftwareApplication",
  "name": "工具名",
  "applicationCategory": "BusinessApplication",
  "operatingSystem": "Web",
  "offers": {
    "@type": "Offer",
    "price": "99.00",
    "priceCurrency": "CNY"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.5",
    "reviewCount": "100"
  }
}
```

### 预期数据

- 3 个月:知乎答案进入搜索前 3
- 6 个月:关键词前 5
- 12 个月:行业权威

### 避坑

- ❌ 不要在知乎做软广(容易被举报)
- ❌ 百家号不要批量发(会被降权)
- ❌ 公众号不要复制别人文章

## 5.3 电商零售行业

### 行业特点

- 流量分散(淘宝/京东/抖音/小红书)
- 内容更新快
- 评价是核心
- 主要靠**小红书 + 抖音 + 百度 + 淘宝**

### GEO 优化重点

**1. 小红书 + 抖音(2024 后权重高)**

```
策略:
- 每个 SKU 一个笔记/视频
- 标题含"对比/推荐/2026"
- 内容含数据来源
- 评论区回答买家关心问题
```

**2. 百度系**

```
- 百度爱采购(B2B 必备)
- 百度小店(零售)
- 百家号(产品介绍)
- 百度地图(本地店)
```

**3. Schema 重点**

```json
{
  "@type": "Product",
  "name": "产品名",
  "brand": "品牌名",
  "offers": {
    "price": "99.00",
    "priceCurrency": "CNY",
    "availability": "InStock"
  },
  "aggregateRating": {
    "ratingValue": "4.5",
    "reviewCount": "100"
  }
}
```

### 预期数据

- SKU 页面收录率:
 - 普通:30%
 - 加 Schema 后:85%
 - 加 FAQ + 对比表:95%

### 避坑

- ❌ 不要用同一文案发所有平台
- ❌ 价格不要写"面议"
- ❌ 库存不要虚假

## 5.4 教育培训行业

### 行业特点

- 决策周期长
- 内容质量敏感
- 信任要求高
- 主要靠**知乎 + 公众号 + 百家号 + 视频号**

### GEO 优化重点

**1. 内容质量第一**

```
- 每篇内容 > 2000 字
- 加导师/教师 bio
- 引用权威数据
- 加学员案例(数据化)
```

**2. E-E-A-T 建设**

```
- 教师资历:学历 + 行业经验
- 机构资质:办学许可
- 媒体报道:新闻源
- 学员评价:数据化
```

**3. 视频化(2024 后重要)**

```
- 视频号/B 站:每个课程 1 个视频
- 知乎视频回答
- 抖音:知识分享
```

### 关键 Schema

```json
{
  "@context": "https://schema.org",
  "@type": "Course",
  "name": "课程名",
  "description": "...",
  "provider": {
    "@type": "Organization",
    "name": "机构名"
  },
  "hasCourseInstance": {
    "courseMode": "online",
    "price": "999.00"
  }
}
```

### 避坑

- ❌ 不要夸大效果
- ❌ 不要伪造成绩单
- ❌ 不要"全网最低价"

## 5.5 医疗健康行业(最严!)

### 行业特点

- YMYL(Your Money Your Life)行业
- 百度 E-A-T 评分最严
- 法规严
- 主要靠**百度健康 + 公众号 + 短视频**

### GEO 优化重点

**1. 必须有医疗资质**

```
- 医疗机构执业许可证
- 医生执业证
- 医疗广告审查证明
- 显示在网站 footer
```

**2. 内容必须专业**

```
- 每个内容由有资质的医生写或审核
- 加医生署名 + 头像
- 加发布/修改日期
- 引用权威医学文献
- 不夸大疗效
```

**3. Schema**

```json
{
  "@context": "https://schema.org",
  "@type": "MedicalOrganization",
  "name": "医院名",
  "address": "...",
  "telephone": "...",
  "medicalSpecialty": ["内科", "外科"]
}
```

### 避坑(医学特有!)

- ❌ 不要用"最好/第一/唯一"等极限词
- ❌ 不要承诺疗效
- ❌ 不要医生未审核的内容
- ❌ 不要没有医疗广告审查的推广

## 5.6 B2B 制造行业(高客单价)

### 行业特点

- 客户决策周期长(6-12 月)
- 询盘价值高(单笔几百万)
- 内容影响大
- 主要靠**百度 + 阿里巴巴 + 行业网 + 展会**

### GEO 优化重点

**1. 行业专业内容**

```
- 技术文档(详细,白皮书)
- 案例研究(数据化)
- 行业标准引用
- 技术专利展示
```

**2. 阿里巴巴 + 中国制造网**

```
- 产品详情页(完整,含技术参数)
- 关键词全覆盖
- 视频展示
- 工厂实景
```

**3. 百度爱采购 + 百度 B2B**

```
- 入驻百度爱采购
- 产品标题含关键词
- 详情页有 Schema
```

### 预期数据

- B2B 产品页收录率:
 - 普通:30%
 - 加 Schema + 案例:80%
- 3 个月:行业关键词前 10
- 询盘 +50%

### 避坑

- ❌ 不要虚假"国内第一/全球领先"
- ❌ 不要伪造检测报告
- ❌ 不要"价格最低"宣传
- ❌ 不要直接复制竞品描述

---

## 5.7 跨行业最佳实践

### 任何行业都做

- [ ] Schema 完整(Product/Article/Organization/FAQ)
- [ ] llms.txt 文件
- [ ] robots.txt 允许 AI
- [ ] FAQ 块(每篇)
- [ ] 对比表(每篇)
- [ ] 数据 + 来源(每篇)
- [ ] 作者署名 + bio
- [ ] 跨平台内容

### 行业特殊要求

| 行业 | 特殊要求 |
|---|---|
| 医疗 | 医生署名 + 医疗资质 + 不可极限词 |
| 教育 | 教师资历 + 学员数据 + 不可夸大 |
| 金融 | 风险提示 + 监管资质 + 不可承诺收益 |
| 电商 | 产品 Schema + 评论 + 价格透明 |
| B2B | 技术文档 + 案例数据 + 工厂实景 |
