## 6.5 防御原则

### 5 大原则

1. **白帽优先**(长期 ROI 最高)
2. **基础设施 > 内容改写**(C-SEO Bench 2025 实证)
3. **质量 > 数量**
4. **持续监测**(GEO 是动态战场)
5. **E-E-A-T 是核心**

### 5 级防御清单

**第一级:内容审查(每周)**
```
□ 没有 Cloaking
□ 没有 Sneaky Redirect
□ 没有 Doorway Pages
□ 没有隐藏文字
□ 关键词密度 < 3%
□ 没有自动生成内容
```

**第二级:链接审查(每月)**
```
□ 监控反向链接
□ 没有 Link Farm
□ 没有 PBN
□ 没有付费链接
□ Disavow 文件更新
```

**第三级:基础设施审查(每月)**
```
□ robots.txt 一致
□ sitemap 真实
□ Schema 验证
□ JS 渲染测试
□ 移动端一致
```

**第四级:AI 内容审查(每季度)**
```
□ 没有 LLM Prompt Injection
□ 没有 RAG 投毒
□ 没有实体混淆
□ E-E-A-T 信号完整
```

**第五级:外部监控(实时)**
```
□ 反向链接突然增多
□ 内容被复制
□ AI 引用是否准确
□ 平台政策更新
```

## 6.6 本章总结

### 关键原则
- **白帽优先,灰帽谨慎,黑帽不做**
- **基础设施 > 内容改写**
- **C-SEO Bench 2025 实证**

### 防御层级
- 内容/链接/基础设施/AI/外部 5 级

### 风险评估
- 国际:Google 算法 + 法规
- 国内:百度 + 国内法规(更严)
- AI 时代:新形态操纵出现

### 立即行动
- 每月做 5 级审查
- 任何新手法出现 → 立即识别 + 防御
