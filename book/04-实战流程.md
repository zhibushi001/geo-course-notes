## 4.1 30 天行动计划(逐日)

### 第 1 周:基础建设(每天 30 分钟)

#### Day 1: 评估现状(30 分钟)

```bash
# 1. 跑准备度审计
python geo_audit.py https://example.com

# 2. 跑 AI 爬虫检查
python check_ai_crawlers.py https://example.com

# 3. 估算 ROI
python geo_roi_calculator.py
```

记录:
- 初始评分
- 哪些 AI 爬虫被允许
- 预期 ROI

#### Day 2: 配置 robots.txt(15 分钟)

在网站根目录创建/修改 `robots.txt`:
```txt
User-agent: GPTBot
Allow: /
User-agent: ClaudeBot
Allow: /
User-agent: PerplexityBot
Allow: /
User-agent: Bytespider
Allow: /
User-agent: Google-Extended
Allow: /

Sitemap: https://example.com/sitemap.xml
```

**验证**:
```bash
python check_ai_crawlers.py https://example.com
```

#### Day 3: 创建 llms.txt(30 分钟)

```bash
python llms_txt_generator.py https://example.com -o llms.txt
```

**手动补充**:
- 公司描述
- 主要产品 + 链接
- 关键数据
- 关于 + 团队

上传到 `https://example.com/llms.txt`

#### Day 4: 添加 Organization Schema(20 分钟)

```bash
python schema_generator.py --type organization
```

输出 JSON 嵌入到所有页面 `<head>`。

#### Day 5: 验证 Schema(15 分钟)

- Google Rich Results Test: https://search.google.com/test/rich-results
- 修复错误

#### Day 6: 提交百度资源平台(30 分钟)

1. 访问 https://ziyuan.baidu.com/
2. 验证站点
3. 提交 sitemap
4. 主动推送 10 条 URL

#### Day 7: 第一次复盘(30 分钟)

- 跑 `geo_audit.py` 看评分变化
- 跑 `prompt_15.py` 看 AI 引用
- 调整下周计划

---

### 第 2 周:内容优化(每天 1 小时)

#### Day 8-9: 重写首页第一段(1.5 小时)

- 用 [第 3 章 3.1 节](03-内容策略.md) 的模板
- 50-80 字符含直接答案 + 2 数据
- 用 schema_generator 验证

#### Day 10-11: 加 5 个 FAQ 块(2 小时)

- 选 5 个核心页面
- 每个加 3-5 个 Q&A
- 用 schema_generator 生成 FAQPage
- 答案 40-60 词含数据

#### Day 12: 加 3 个对比表(1.5 小时)

- 选 3 个核心页面
- 5-8 行 x 3-5 列
- 你的优势放右列

#### Day 13: 加 Article Schema(1 小时)

```bash
python schema_generator.py --type article
```

#### Day 14: 第二次复盘(30 分钟)

- 跑所有工具
- 记录引用率变化
- 调整下周

---

### 第 3 周:品牌权威(每天 1-2 小时)

#### Day 15-16: 申请百度百科(2-3 小时)

**条件**:
- 公司符合 Notability(有新闻报道、奖项)
- 有可靠来源

**步骤**:
1. 注册百度账号
2. 创建词条
3. 引用可靠来源
4. 等待审核(1-2 周)

#### Day 17: 完善作者 bio(1 小时)

- 每篇内容加作者署名
- LinkedIn 链接
- bio 完整

#### Day 18-19: 知乎深度文(3 小时)

- 选 2 个行业问题
- 写 1500+ 字深度回答
- 用模板(第一段含答案 + FAQ)
- 加外链到主站

#### Day 20-21: 百家号 + 小红书(2 小时)

- 百家号:每天 1 篇
- 小红书:每 2 天 1 个图文

---

### 第 4 周:监测 + 优化(每天 30 分钟)

#### Day 22-23: 完整 15 提示词测试(1 小时)

```bash
python prompt_15.py "你的品牌" -o test.md
# 去 6 大 AI 平台问
# 记录结果
```

#### Day 24: 跑 ROI 重新估算(15 分钟)

```bash
python geo_roi_calculator.py
```

#### Day 25-27: 加 2 篇深度长文(3 小时)

- 每篇 2000+ 字
- 含 FAQ + 对比表 + 数据
- 跨平台分发

#### Day 28-29: 加 5 个 FAQ 块(2 小时)

- 找更多机会加 FAQ

#### Day 30: 月度复盘(1 小时)

- 评分对比
- AI 引用率
- 流量变化
- 下月计划

## 4.2 5 大核心流程

### 流程 1:评估流程

```
Step 1: 跑 geo_audit.py → 评分
Step 2: 跑 check_ai_crawlers.py → AI 爬虫
Step 3: 跑 prompt_15.py → 引用率
Step 4: 跑 geo_roi_calculator.py → ROI
Step 5: 30 分钟报告
```

### 流程 2:配置流程

```
Step 1: 配置 robots.txt(15 分钟)
Step 2: 创建 llms.txt(30 分钟)
Step 3: 添加 Organization Schema(20 分钟)
Step 4: 提交 sitemap(15 分钟)
Step 5: 验证(15 分钟)
```

### 流程 3:内容生产流程

```
Step 1: 选关键词(20 分钟)
Step 2: 研究竞品(30 分钟)
Step 3: 写初稿(2 小时)
Step 4: 添加 FAQ + 对比表(30 分钟)
Step 5: 加 Schema(15 分钟)
Step 6: 跨平台分发(1 小时)
Step 7: 提交百度(10 分钟)
```

### 流程 4:跨平台分发流程

```
Step 1: 主站发布(完整版)
Step 2: 知乎发布(问答版)
Step 3: 百家号发布(资讯版)
Step 4: 小红书发布(图文笔记)
Step 5: 公众号发布(深度版)
Step 6: 每平台加原文链接
```

### 流程 5:持续监测流程

```
每日:
- 看 UptimeRobot
- 推 10-20 条新 URL 到百度

每周:
- 跑 prompt_15
- 修复发现的错误

每月:
- 跑 geo_audit
- 跑 geo_roi_calculator
- 月度报告

每季度:
- 全盘评估
- 调整策略
```

## 4.3 持续优化机制

### 监测指标(每月追踪)

| 指标 | 目标 | 跟踪频率 |
|---|---|---|
| AI 引用率 | 30% → 60% | 每周 |
| GEO 评分 | 60 → 80 | 每月 |
| 收录率 | 50% → 90% | 每月 |
| AI 流量 | 增长 | 每周 |
| 转化率 | 提升 | 每月 |
| ROI | 正 | 每月 |

### 优化循环

```
数据收集(每周)
   ↓
分析(每月)
   ↓
策略调整
   ↓
实施
   ↓
再测量
   ↓
循环
```

### 团队协作

| 角色 | 责任 |
|---|---|
| **SEO 负责人** | 整体策略、工具配置、监测 |

| **设计师** | 数据可视化、模板定制 |
| **开发者** | Schema 实施、技术问题 |
| **运营** | 跨平台分发、社群运营 |
