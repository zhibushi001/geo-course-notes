## 7.4 ROI 计算公式

> 完整内容在 [../实战工具/ROI计算公式.md](../实战工具/ROI计算公式.md)

### 核心公式

```
月增量利润 ≈ 当前月利润 × 30%(中等预估)
月 ROI = 当前月利润 × 30% / GEO 投入 × 100%
```

### 估算器

```bash
python geo_roi_calculator.py
```

### 投资分级

| 阶段 | 月投入 | 预期回报 |
|---|---|---|
| 入门 | ¥0-1k | 1.2x |
| 基础 | ¥1k-5k | 1.5-2x |
| 进阶 | ¥5k-20k | 2-3x |
| 专业 | ¥20k-100k | 3-5x |
| 企业 | ¥100k+ | 5x+ |

### 行业 ROI 预期

| 行业 | 月 ROI |
|---|---|
| B2B SaaS | 200-500% |
| 电商 | 100-300% |
| 教育 | 150-400% |
| 医疗 | 50-150%(严) |
| B2B 制造 | 300-1000% |
