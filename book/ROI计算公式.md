## 🎯 核心公式

### 基础公式

```
GEO 月 ROI = (GEO 增量月利润 / GEO 月投入) × 100%
GEO 年 ROI = (年增量利润 / 年投入) × 100%
回本月数 = GEO 投入 / 月增量利润
```

### 详细公式

```
月增量利润 = 月增量营收 × 利润率
月增量营收 = 月新增客户数 × 客单价
月新增客户数 = 月流量增量 × 转化率
月流量增量 = 当前月流量 × GEO 流量提升系数
GEO 流量提升系数 = f(技术分,内容分,品牌分)
```

### 简化版

```
月增量利润 ≈ 当前月利润 × 30%(中等预估)
月 ROI = 当前月利润 × 30% / GEO 投入 × 100%
```

**示例**:
- 当前月利润:5 万元
- GEO 投入:1 万元/月
- 预估增量:5万 × 30% = 1.5 万
- 月 ROI:150%
- 回本:1万 / 1.5万 = 0.67 月

## 📐 关键指标公式

### 1. GEO 准备度评分

```
GEO 准备度 = (技术分 × 40%) + (内容分 × 40%) + (品牌分 × 20%)

技术分(0-100):
- robots.txt 允许 AI 爬虫: 0-30
- llms.txt 存在且完整: 0-20
- Schema.org 标记: 0-20
- sitemap.xml 完整: 0-15
- 移动端适配: 0-15

内容分(0-100):
- FAQ 块数量: 0-20
- 对比表数量: 0-15
- 第一段含答案: 0-20
- 数据来源引用: 0-20
- 章节结构清晰: 0-15
- 长度合适(1500+): 0-10

品牌分(0-100):
- 百度百科: 0-30
- 媒体报道: 0-25
- 行业奖项: 0-20
- 客户评价: 0-15
- 创始人 bio: 0-10
```

### 2. AI 引用率

```
AI 引用率 = 被引用次数 / 测试提示词总数 × 100%

测试提示词 = 7(类别发现) + 5(品牌评估) + 3(竞品对比) = 15
```

### 3. 月度增长

```
月度增长 = (本月引用率 - 上月引用率) / 上月引用率 × 100%
```

### 4. 单次 GEO 优化成本

```
单次成本 = 月投入 / 月内容产出数量

例:月投入 5000,产出 10 篇内容 → 单次 500 元/篇
```

## ⚠️ ROI 估算的 3 大误区

### 误区 1:只看短期

**错误**:看第 1 个月数据就下结论
- GEO 是长期游戏(3-6 个月积累)
- 第 1 个月可能 ROI = 0(还没见效)
- 6 个月后 ROI 可能 = 500%

### 误区 2:只看流量

**错误**:只看流量增量
- 流量多但质量差 → 转化率下降
- 应该看**最终利润**增量

### 误区 3:忽略沉没成本

**错误**:只算新投入
- 团队时间(隐性成本)
- 内容创作时间(隐性成本)
- 工具学习成本(隐性成本)
