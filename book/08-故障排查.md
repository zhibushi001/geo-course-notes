## 8.1 4 步诊断流程

```
GEO 不生效
    ↓
[Step 1] 基础设施检查(20 分钟)
    ↓ (如果通过)
[Step 2] 内容质量检查(30 分钟)
    ↓ (如果通过)
[Step 3] AI 引用检查(1-2 小时)
    ↓ (如果通过)
[Step 4] 时机和长期因素(等待)
```

### Step 1: 基础设施(20 分钟)

```bash
# 1. AI 爬虫
python check_ai_crawlers.py https://example.com

# 2. GEO 准备度
python geo_audit.py https://example.com

# 3. llms.txt
curl https://example.com/llms.txt

# 4. sitemap
curl https://example.com/sitemap.xml
```

### Step 2: 内容质量(30 分钟)

检查:
- [ ] 标题 50-60 字符含关键词
- [ ] 第一段含直接答案
- [ ] 长度 > 1500 字
- [ ] 有 FAQ 块
- [ ] 有对比表
- [ ] 数据有来源
- [ ] 作者署名

### Step 3: AI 引用(1-2 小时)

```bash
python prompt_15.py "你的品牌" -o test.md
# 去 6 大 AI 平台问
# 记录结果
```

### Step 4: 长期因素

- 新站需要 3-6 个月
- 关键词竞争激烈
- 等待 + 持续优化

## 8.2 14 个真实故障案例(摘要)

> **完整内容在 [../实战工具/故障案例库.md](../实战工具/故障案例库.md)**

### 案例 1:robots.txt 阻止 AI 爬虫

**症状**:百度/Google 收录正常,AI 不引用
**根因**:只配 Googlebot,其他 AI 默认被 * 阻止
**修复**:5 分钟,加 AI 爬虫规则

### 案例 2:llms.txt 存在但 AI 不读

**症状**:llms.txt 200,但 AI 不引用
**根因**:内容太简略(< 100 字)
**修复**:2-4 小时,补完整内容

### 案例 3:Schema 错误

**症状**:Schema.org 通过,但搜索结果不显示富文本
**根因**:数据不完整,或类型不匹配
**修复**:2-4 周(等 Google 重处理)

### 案例 4:AI 引用但不带来流量

**症状**:15 提示词 60% 引用率,但流量没增加
**根因**:AI 引用但不点链接
**修复**:加 CTA、匹配语境

### 案例 5:内容质量高但百度不收录

**症状**:原创 + 数据,提交后 1 个月不收录
**根因**:新站权重低、服务器慢、内容短
**修复**:1-3 个月

### 案例 6:突然掉量

**症状**:引用率 50% 突然掉到 20%
**根因**:AI 平台政策变化、竞品发布新内容
**修复**:1-2 周

### 案例 7:Schema 与实际不符

**症状**:价格/库存错误,被警告
**根因**:Schema 反映的数据不准
**修复**:1-2 周

### 案例 8:多平台被识别为重复

**症状**:主站 + 知乎 + 百家号,只引用最早的
**根因**:内容一字不差,canonical 错误
**修复**:1-2 周

### 案例 9:训练数据污染

**症状**:竞品编辑维基,AI 引用错误信息
**根因**:AI 训练数据被污染
**修复**:1-6 个月

### 案例 10:内容农场模式

**症状**:每天 10+ 篇,引用率反降
**根因**:触发内容农场检测
**修复**:1-3 个月

### 案例 11:负面 SEO 攻击

**症状**:收录下降,反向链接暴增
**根因**:竞品发垃圾链接
**修复**:2-4 周

### 案例 12:AI 内容检测误判

**症状**:人工写,被检测为 AI
**根因**:文风太"完美"
**修复**:重写

### 案例 13:关键词竞争激烈

**症状**:关键词前 3 都被大站占
**根因**:关键词难度太高
**修复**:6-12 个月

### 案例 14:移动端不友好

**症状**:桌面端 80,移动端 30
**根因**:移动端布局/速度问题
**修复**:1-2 周

## 8.4 紧急情况处理

### 突然掉量应急

```bash
# 1. 立即检查基础设施(5 分钟)
python check_ai_crawlers.py https://example.com
python geo_audit.py https://example.com

# 2. 检查最近修改
git log --since="1 week ago"

# 3. 检查流量来源
百度统计 / Google SC / 看哪个页面掉

# 4. 立即行动:
# - 发 3-5 篇新内容
# - 检查 robots.txt
# - 提交百度 + 主动推送
# - 跨平台分发
```

**恢复时间**:1-2 周

### 负面 SEO 攻击应急

```bash
# 1. 拒绝 spam 链接
百度站长平台 → 拒绝外链

# 2. 提交 spam 链接
百度反作弊中心

# 3. 举报镜像
DMCA / 法律手段

# 4. 加强 robots.txt
5. 监控流量来源
```

**恢复时间**:2-4 周

### Schema 错误应急

```bash
# 1. 修正 Schema
# 2. 验证(Google Rich Results)
# 3. 重新提交
# 4. Search Console 看处理
```

**恢复时间**:1-2 周

## 8.6 防御原则

### 每月例行检查

```bash
# 1. AI 爬虫可见
python check_ai_crawlers.py https://example.com

# 2. GEO 准备度
python geo_audit.py https://example.com

# 3. AI 引用率
python prompt_15.py "你的品牌"

# 4. 流量来源
看百度统计 / Google SC

# 5. 内容质量
每月跑 1 次内容质量检查
```

### 预警信号

| 信号 | 含义 | 行动 |
|---|---|---|
| 引用率下降 20%+ | 可能被检测 | 检查基础设施 |
| llms.txt 失效 | robots 错误 | 检查配置 |
| 流量突然下跌 | 负面 SEO 或处罚 | 紧急诊断 |
| Schema 警告 | 标记错误 | 修复 |
| 收录下降 | 内容问题 | 重写 |
