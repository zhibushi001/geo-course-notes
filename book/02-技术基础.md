## 2.1 4 大基础设施(必做)

### 2.1.1 robots.txt - 允许 AI 爬虫

**作用**:告诉 AI 爬虫"可以访问我的网站"

**12 个 AI 爬虫**:
- GPTBot(OpenAI 训练)
- ChatGPT-User(用户触发)
- OAI-SearchBot(OpenAI 搜索)
- ClaudeBot(Anthropic 训练)
- Claude-Web(Anthropic 用户)
- PerplexityBot(Perplexity 搜索)
- Perplexity-User
- Google-Extended(Gemini 训练)
- Applebot-Extended(Apple 训练)
- Bytespider(豆包训练)
- CCBot(Common Crawl)
- cohere-ai(Cohere 训练)

**标准 robots.txt**:
```txt
# 传统爬虫
User-agent: Googlebot
Allow: /

User-agent: Baiduspider
Allow: /

# AI 训练爬虫
User-agent: GPTBot
Allow: /

User-agent: ChatGPT-User
Allow: /

User-agent: OAI-SearchBot
Allow: /

User-agent: ClaudeBot
Allow: /

User-agent: Claude-Web
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: Perplexity-User
Allow: /

User-agent: Google-Extended
Allow: /

User-agent: Applebot-Extended
Allow: /

User-agent: Bytespider
Allow: /

# 站点地图
Sitemap: https://example.com/sitemap.xml
```

**自动化检查**:
```bash
python check_ai_crawlers.py https://example.com
```

### 2.1.2 llms.txt - 给 LLM 的"自我介绍"

**作用**:LLM 在索引网站时,会优先看 llms.txt 了解网站

**完整模板**:见 [07-工具与代码.md §7.2.1](07-工具与代码.md)

**最少包含**:
- 品牌名 + 定位
- 主要产品/服务(带链接)
- 关键数据
- 关于我们

**自动生成**:
```bash
python llms_txt_generator.py https://example.com -o llms.txt
# 上传到 https://example.com/llms.txt
```

### 2.1.3 Schema.org - 结构化数据

**作用**:告诉搜索引擎和 AI"这段内容是什么"

**6 种常用 Schema**:
1. Article(文章)
2. FAQPage(常见问题)
3. Product(产品)
4. Organization(组织)
5. BreadcrumbList(面包屑)
6. HowTo(操作指南)

**生成代码**:
```bash
# 交互式
python schema_generator.py

# 命令行
python schema_generator.py --type faq -o faq.json
```

**插入到网页**:
```html
<head>
  <script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "Article",
    "headline": "GEO 是什么?",
    "author": {
      "@type": "Person",
      "name": "作者名"
    },
    "datePublished": "2026-08-20"
  }
  </script>
</head>
```

**验证**:
- Google: https://search.google.com/test/rich-results
- Schema.org: https://validator.schema.org/

### 2.1.4 sitemap.xml - 网站结构

**作用**:告诉爬虫网站有哪些页面

**最少包含**:
- 所有公开 URL
- 最后修改时间
- 更新频率
- 优先级

**提交到**:
- 百度搜索资源平台
- Google Search Console
- Bing Webmaster

## 2.2 GEO 8 维度评分体系

**来源**:Auriti-Labs/geo-optimizer-skill(⭐721)

| 维度 | 分值 | 核心检查项 |
|---|---|---|
| **Robots.txt** | 18 | 27 个 AI bot 的访问规则 |
| **llms.txt** | 18 | 是否存在 + 结构 + llms-full.txt |
| **Schema JSON-LD** | 16 | 多类型 + 完整 + 5+ 属性 |
| **Meta 标签** | 14 | title + description + canonical + OG |
| **内容质量** | 12 | H1 + 数据 + 引用 + 列表表格 |
| **品牌权威** | 10 | KG 链接 + about 页 + topic authority |
| **信号** | 6 | RSS + dateModified + freshness |
| **AI Discovery** | 6 | .well-known/ai.txt 等 |
| **总分** | **100** | 86+ 优秀,68-85 良好 |

**评分标准**:
- **86-100**:优秀
- **68-85**:良好
- **36-67**:基础
- **0-35**:关键缺失

**自动审计**:
```bash
python geo_audit.py https://example.com
```

**额外检查**(不计入评分但很重要):
- CDN Crawler Access(Cloudflare 等)
- JS Rendering(SPA 检测)
- WebMCP Readiness
- Negative Signals(CTA 过多等)
- Prompt Injection Detection
- Trust Stack Score
- RAG Chunk Readiness
- Content Decay Prediction
- Platform Citation Profile
- Multimodal Readiness

## 2.3 工具配置(8 大工具)

- URL: https://search.google.com/search-console/
- 功能:看 Google 索引、抓取错误

### 2.3.3 Bing Webmaster Tools

- URL: https://www.bing.com/webmasters
- 功能:Copilot / Perplexity / ChatGPT-User 用 Bing
- 配置:Bing 标记 / XML / meta

### 2.3.4 百度统计

- URL: https://tongji.baidu.com/
- 功能:看流量来源 + 用户行为
- 关键指标:停留时间、跳出率、页面深度

- 用途:检测 AI 爬虫 / Schema / 内链

### 2.3.6 Ahrefs / SEMrush

- 功能:综合 SEO 工具
- 用途:反向链接、关键词、内容差距
